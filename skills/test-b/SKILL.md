# test-B：口播稿 → 剪辑方案

接收 test-A 交接的口播稿或用户直接提供的稿件，给出可以指导拍摄和后续剪辑的方案。完整稿件在当前对话里时直接使用，沿用用户最近认可的版本和限制，无需重新粘贴。

## 生成方案

1. 识别口播的开场、解释、例子和结尾，保留作者的事实、立场与核心表达。用户未指定时，按单人竖屏口播设计；缺少成片时长时依据稿件估计并明确标注。
2. 读取 [plan-fields.md](references/plan-fields.md)，按语义段落输出剪辑方案。每段关联稿件中的具体句子，说明剪辑动作、字幕重点、画面建议和声音处理。
3. 没有录像时，照常给出基于文稿的规划。段落时长只能作为估计，不编造素材路径、源片时间码、已存在镜头或精确切点。建议补拍或制作的画面明确标注为待准备。
4. 优先保持完整意思和自然口播节奏。剪切落在句意或话题转折处，避免每个短句都切镜头；字幕只强调关键点。沿用已有视觉素材限制，默认不把大量素材采购设为完成前提。
5. 先在对话中交付完整方案及确实影响执行的待确认项。用户要求文件时再保存到指定位置。核心稿件完全缺失才询问输入；缺少录像不阻止方案交付。

本 Skill 交付剪辑方案，不把它描述为已生成的视频或可直接导入剪映的工程。实际素材切点、路径和字幕时序在拿到录像后核对；用户后续要求生成工程时再进入相应制作流程。

## 最小化统计

统计来源与关闭方式见 [privacy.md](references/privacy.md)。仅在本机有用户同意统计后留下的推荐来源文件、且用户当前未拒绝统计时运行脚本。独立使用 B 且没有来源文件时不补造来源、不上报。

- 在开始工作时可运行 `bash <test-b目录>/scripts/first-run.sh`，脚本会去重安装成功上报。
- 完整剪辑方案已经生成并准备交付时，再运行 `bash <test-b目录>/scripts/report.sh first_use_success`，记录首次完成方案。只有介绍功能、追问输入、输出空表或任务中断时不记首次使用成功。
- 用户拒绝统计或设置 `ROS_NO_TELEMETRY=1` 时跳过两个脚本；统计失败不阻断交付。

所有命令使用当前 Skill 的绝对目录。仅发送来源、目标 Skill、随机安装标识与事件类型，不发送口播稿、素材、对话或本地路径。不要修改任何 DBS Skill。
